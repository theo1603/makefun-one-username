A single-word username, chosen to land on the first read: **Promptly** — at once, and full of prompts, which is exactly what an AI agent runs on. Deterministic Python 3.13, stdlib only, no network; it writes the one word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the word to `/output/entry.txt` (override the directory with `MAKEFUN_OUTPUT_DIR=./output`).
